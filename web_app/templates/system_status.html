Voice Routing to Caller (Optional)

To let callers hear AI voice output (from Settings → Voice Output), route the app's audio into your call app's microphone input using a free virtual audio cable.

{% if host_platform == 'win32' %}

Windows: VB-Cable

  1. Install VB-Cable (free) from vb-audio.com/Cable.
  2. In Zoom/Meet/WhatsApp call settings, set CABLE Input (VB-Audio Virtual Cable) as the microphone.
  3. Set your Windows playback device to CABLE Input so app audio plays into it, or select it as the output for the Speak button's audio.
Download VB-Cable
{% elif host_platform == 'darwin' %}

Mac: BlackHole

  1. Install BlackHole (free, 2ch) from existential.audio/blackhole.
  2. In Zoom/Meet/WhatsApp call settings, set BlackHole 2ch as the microphone.
  3. Route the app's audio output through BlackHole so the Speak button's voice reaches the call.
Download BlackHole
{% else %}

Linux: PulseAudio / PipeWire

  1. Create a null sink / loopback module (PulseAudio) or a virtual sink (PipeWire).
  2. Set your call app's microphone input to that virtual sink's monitor source.
  3. Route the app's audio output to the same virtual sink.
{% endif %}

This step is optional — the Speak button works through your normal speakers without it; a virtual cable is only needed so the other person on the call can hear it too.
